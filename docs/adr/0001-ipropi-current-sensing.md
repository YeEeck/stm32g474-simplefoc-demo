# 0001 IPROPI 内置电流检测作为电流环采样源

驱动板无外置采样电阻，DRV8316CT 内置电流检测（IPROPI，三路模拟输出 SOA/SOB/SOC，增益由板上引脚配置固定）已接出到主控 ADC。电流环需要真实相电流反馈，因此采用 IPROPI 输出作为采样源，并为 SimpleFOC 编写自定义 `CurrentSense` 适配类。

放弃的方案：加外置采样电阻（需要改板，违背"优先用现成库、不动硬件"的约束）；商家建议的电压开环扭矩控制（无电流反馈，无法限流，不满足"基础电流环"的明确需求）。

后果：IPROPI 输出是内部低通滤波后的电流信号，带宽有限，需将采样时刻对齐 PWM 并降低电流环带宽预期（详见 design.md 调参章节）；实际增益无法经 SPI 读取，需在调参阶段标定。
