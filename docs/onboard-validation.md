# 上板验证指导（Bench Test Guide）

按本指南在真实硬件上逐阶段验证扭矩控制 demo。每一步都有明确的预期结果与异常排查。**在开始前先完成本仓库的所有代码构建验证（`test/sil` 全过、固件编译通过）**。

---

## 1. 准备

### 1.1 工具清单

| 工具 | 用途 |
|---|---|
| DAP-Link（SWD） | 烧录与调试 |
| USB-TTL 或 DAP 虚拟串口 | 串口 115200 |
| 可调限流电源（0~24V，限流 0.5A 起步） | VM 供电 |
| 万用表 | IPROPI 标定、电源电流检查 |
| 示波器（可选） | PWM 波形、采样时刻验证 |
| 串口终端（minicom/picocom/screen） | 命令行交互 |

### 1.2 安全须知

- **电机必须固定**（夹具/胶带），防止对齐与测试时飞转伤人
- 首次上电电源**限流 0.5A**，确认无异常后再提高限流（≤ 3A）
- 上电顺序：先接好全部信号线 → 再上 VM → 最后上主控电（或同时）
- 运行中禁止用手直接接触转子/轴；堵转测试控制在 2A 以内、单次 ≤ 5 秒
- 驱动板无 nFAULT 接出，**故障不可见**——异常时立即断电排查

### 1.3 接线清单（最终映射）

| 信号 | 主控引脚 | 备注 |
|---|---|---|
| INH_A/B/C | PA8 / PA9 / PA10 | 驱动板 INH 输入 |
| SOA/SOB/SOC | PA0 / PA1 / PA3 | 驱动板 IPROPI 输出 |
| MT6701 A / B | PA6 / PA7 | 编码器 A/B |
| MT6701 Z | PB4 | 编码器 Z（上电对齐辅助） |
| nSLEEP | PC7 | 驱动板唤醒 |
| UART TX/RX | PD5 / PD6 | USB-TTL（TX↔RX 交叉） |
| SWDIO/SWCLK | PA13 / PA14 | DAP-Link |
| VM / GND | 电源 | 24V，先限流 |

INLx 已由驱动板接地；电机三相接驱动板输出（线序任意，对齐时自动校正相位——若方向不对可用 `MS0` 或交换两相）。

**接线后自查**：每根信号逐一核对；上电前用万用表确认 VM 与 GND 无短路。

## 2. 烧录

### 2.1 EIDE 路线（推荐）

1. VS Code 打开 `firmware/stm32g474-simplefoc-demo/` 工作区
2. 构建（EIDE 侧栏 → 构建）
3. 下载（EIDE 侧栏 → 下载，OpenOCD + CMSIS-DAP 自动配置）

### 2.2 Makefile 路线

```bash
cd firmware && make -j8
# 产物：build/stm32g474-simplefoc-demo.bin
# 用 DAP 烧录（openocd cmsis-dap）：
openocd -f interface/cmsis-dap.cfg -f target/stm32g4x.cfg \
  -c "program build/stm32g474-simplefoc-demo.bin 0x08000000 verify reset exit"
```

## 3. 分阶段验证

### 阶段 1：上电与串口

**目标**：固件启动、驱动板唤醒、串口通信正常。

**步骤**：
1. 上电（限流 0.5A）→ 打开串口终端 115200 → 复位主控
2. 观察启动日志

**预期**：
- 串口出现（约 1 秒内）：
  ```
  MOT:Init
  MOT:Enable driver.
  MOT:Align sensor.
  MOT:sensor dir: CW        （或 CCW，取决于安装）
  MOT:Zero elec. angle: x.xx
  MOT:Align current sense.
  MOT:Success: 1
  MOT:Ready.
  simplefoc torque demo ready: T<current>A
  ```
- 电源电流 ≤ 50mA（电机静止、无输出）

**异常排查**：
| 现象 | 排查 |
|---|---|
| 无任何输出 | TX/RX 是否交叉；PD5/PD6 接线；GND 共地；波特率 |
| 乱码 | 波特率/电平（3.3V TTL）；TX 接错 |
| 卡在 `MOT:Init` 后无反应 | 驱动板 nSLEEP 未拉高？VM 未上电？检查 PC7 电平与 VM |
| 卡在 `Align sensor.` 后打印 `Failed to notice movement` | 编码器接线/供电错误，角度无变化（见阶段 2） |
| 卡在 `Align current sense.` 后打印 `Align error` | SOx 接线错误/未接；IPROPI 通道与相序不符 |
| `Init FOC fail` | 上述任一对齐失败；检查各信号线 |

### 阶段 2：编码器验证

**目标**：确认 MT6701 角度读数连续、方向正确、Z 正常。

**步骤**：
1. 手动缓慢转动转子，观察串口 monitor 输出（`angle` 字段，0~6.28 rad）
2. 正转与反转各转若干圈，确认角度单调变化、方向对应

**预期**：
- 角度随转动连续变化（0→2π 回绕），无跳变
- monitor 行格式：`target \t Vq \t Iq(mA) \t velocity \t angle`
- 每转一圈 Z 触发一次（计数器被校准，角度无累计漂移）

**异常排查**：
| 现象 | 排查 |
|---|---|
| 角度不变 | A/B 接线、编码器供电（MT6701 需 3.3V）、磁铁是否脱落/距离 |
| 角度跳变/噪声 | A/B 线过长或与 PWM 线并行走线；检查 Z 干扰 |
| 转动方向与预期相反 | 正常——对齐时会自动判定方向；也可交换 A/B |

### 阶段 3：IPROPI 标定（实测复核）

**目标**：验证 CSA 增益 0.15 V/A 与实际一致（设计值 ±5%）。

**步骤**：
1. 静止、`T0` 状态下，串口 monitor 的 `Iq` 应 ≈ 0（±30mA 内）
2. 固定转子（堵转）→ `T0.5` → 万用表串入任一相线测真实电流 I_real
3. 对比 monitor 的 `Iq`（单位 mA）：`Iq_fw ≈ I_real`？

**预期**：`Iq_fw / I_real` 在 0.95~1.05 之间。

**如果偏差 > 5%**：修正 `firmware/App/motor_config.h` 中 `ipropi_gain_v_per_a` → `0.15 × (I_real / Iq_fw)`，重新烧录后复测。

**注意**：堵转时间 ≤ 5 秒；若 T0.5 时 monitor 的 Iq 读数异常（饱和/跳变），检查 SOx 接线与 VREF 供电。

### 阶段 4：对齐验证（initFOC 已在启动时完成）

**目标**：确认上电对齐行为正常（阶段 1 已隐含，此处细化）。

**步骤**：
1. 每次上电，对齐时转子应被短暂锁定/旋转后静止（对齐电压 3V）
2. 对齐完成后电机保持静止、无啸叫、无缓慢漂移

**预期**：
- 启动日志含 `sensor dir`、`Zero elec. angle`、`Success`、`Ready`
- 对齐后 `Iq` 读数 ≈ 0，角度稳定

**异常**：对齐后电机啸叫或缓慢转动 → 电流环未收敛迹象，检查 PID 初值与电流读数（阶段 3/5）。

### 阶段 5：电流环验证与调参

**目标**：`T` 指令闭环工作，电流环收敛无振荡。

**步骤**（小步渐进）：
1. `T0.2` → 电机应产生扭矩并开始转动（轻载下缓慢加速）
2. monitor 观察 `Iq`：应快速（<10ms 量级）收敛到 200mA 附近，无持续振荡
3. 逐步提高：`T0.5` → `T1.0` → `T1.5`（每次观察 5 秒）
4. 若出现振荡/啸叫：降低增益后重试
5. （可选）SimpleFOC Studio 连接串口，图形化观察 Iq 波形

**调参命令**（若需要）：
| 命令 | 含义 | 示例 |
|---|---|---|
| `MQP<值>` | q 电流环 Kp | `MQP1.5` |
| `MQI<值>` | q 电流环 Ki | `MQI5000` |
| `MDP<值>` / `MDI<值>` | d 电流环 Kp/Ki | `MDP1.5` |
| `MLC<值>` | 电流上限（A） | `MLC2` |
| `T<值>` | 目标电流（A） | `T0.5` |
| `T0` | 停止 | `T0` |
| `?` | 扫描命令（Studio 握手） | `?` |
| `@` / `#` | 输出模式 / 小数位 | `@` |

**预期**：`T1.5` 时 `Iq` 稳定在 1500mA ±5%，无振荡；`T0` 后 1 秒内 `Iq` 回零、电机减速停止。

**异常排查**：
| 现象 | 排查 |
|---|---|
| Iq 不跟踪指令（饱和在 ±limit） | 电流反馈符号/增益错误（复查阶段 3）；SOx 相序错 |
| 高频振荡/啸叫 | Kp 过大 → 降 Kp（如 1.5→1.0）；采样时刻偏移（示波器验证） |
| 低频抖动 | Ki 过大 → 降 Ki；机械共振（固定不牢） |
| 电机无力/扭矩小 | 电流实际值低于指令（增益偏大？标定复查）；母线电压不足 |

### 阶段 6：完整功能验收

| 检查项 | 方法 | 通过标准 |
|---|---|---|
| 正反转 | `T0.5` 与 `T-0.5` | 两个方向都转动，Iq 对称 |
| 限流保护 | 堵转下 `T3` | `Iq` 被限制在 2A（`MLC` 值），无失控 |
| 长时间运行 | `T0.5` 持续 10 分钟 | 无漂移、无复位、驱动板温度可手触 |
| 重新上电 | 断电重启 3 次 | 每次对齐成功、无失败 |
| 断电保护 | 运行中断电 | 重新上电后正常（电机停在任意位置也能对齐） |
