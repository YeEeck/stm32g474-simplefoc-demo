# 06 采样触发边沿与注释/设计文档矛盾（需上板示波器验证）

Status: needs-info

## 背景

架构评审（2026-08-01）发现。hardware_api_stm32.cpp:18-19 注释声称"触发点在上溢 = 脉宽中心（电流纹波最小处采样）"；但中心对齐 + RCR=1 下，TRGO2=UPDATE 事件的重复计数器语义（每 2 次溢出/下溢事件一次更新）可能使更新落在计数器下溢（CNT=0，周期边界、INH 全低→高翻转瞬间），与 design.md:104"计数器上溢，占空比中央"矛盾。SIL 直接写 JDR 并回调（hal_stubs.cpp:58-60），绕过硬件触发，无法验证。
